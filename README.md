# Employee Management System

## Overview

A web-based Employee Management System developed using JSP, Servlets, JDBC, MySQL, and Apache Tomcat.

## Features

* User Authentication
* Role-Based Access Control
* Employee CRUD Operations
* Pagination
* Sorting
* Email Notifications using JavaMail
* Session Management
* Responsive Bootstrap UI

## Technologies Used

* Java
* JSP
* Servlets
* JDBC
* MySQL
* Apache Tomcat 10
* Bootstrap 5
* JavaMail API

## Project Structure

* Model
* DAO
* Servlet
* JSP
* Utility Classes

## Setup Instructions

1. Install JDK 17+
2. Install MySQL
3. Create database
4. Import SQL script
5. Configure DBConnection.java
6. Deploy on Apache Tomcat
7. Run the application
